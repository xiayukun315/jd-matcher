# jd-matcher

用一个分数告诉你：这份 JD 我够不够格；不够的话，差在哪。

## 效果

<img width="716" height="406" alt="界面截图" src="https://github.com/user-attachments/assets/23196b51-2d5e-4d64-801a-95b22c9b5bf4" />

输入简历 + JD，输出匹配分、命中项与差距项。
v0.2 会提示「识别词太少，分数不可信」——因为关键词匹配在样本小时会给假分数。

## 是什么

输入一段简历 + 一段岗位描述（JD），输出：

- 匹配分（0–100）
- 命中的技能项
- 没命中的技能项（也就是差距）
- 补齐建议

## 怎么跑

```bash
# 命令行版
python jd_matcher.py jd1.txt

# 界面版
pip install streamlit
python -m streamlit run app.py --server.address 127.0.0.1
```

简历存成 `resume.txt`，岗位描述存成 `jd.txt`（或 `jd1.txt`、`jd2.txt`……），放在同目录，不用改代码。

## 给谁用

给自己。投实习之前先跑一遍，别把时间花在明显不匹配的岗位上。
跑多了还能看出：同一类岗位反复在要什么——那就是你该学的东西。

## 已知局限

关键词匹配有三个硬伤，写在这里免得被分数骗：

1. **样本小时分数失真**：JD 里只识别到 1–2 个技能词时，这个分数没有意义（已加警告）。
2. **看不懂软条件**：学历、年级、实习时长、英语等级这类门槛，工具完全看不见。一份「2027 届 + 六级 + 实习 6 个月」的 JD 可能被算出 100 分。
3. **同义词覆盖有限**：「熟悉 / 掌握 / 了解」在 JD 里是不同要求，工具当同一件事。
