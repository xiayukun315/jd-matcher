# jd-matcher

用一个分数告诉你：这份 JD 我够不够格；不够的话，差在哪。

## 是什么

输入一段简历 + 一段岗位描述（JD），输出：

- 匹配分（0–100）
- 命中的技能项
- 没命中的技能项（也就是差距）
- 补齐建议

## 给谁用

给自己。投实习之前先跑一遍，别把时间花在明显不匹配的岗位上。
跑多了还能看出：同一类岗位反复在要什么——那就是你该学的东西。

## 怎么跑

```bash
python jd_matcher.py
```

改文件底部的 `RESUME` 和 `JD` 两段文字，换成你自己的简历和一份真实岗位描述。
